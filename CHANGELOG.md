# Changelog

All notable changes to Openvelope will be documented in this file.

## [0.2.0] - 2026-06-08

### Added
- Contact management with groups
- Multiple email identities/signatures
- Dark/light theme support
- Keyboard shortcuts for common actions
- Conversation threading view
- Draft auto-save to localStorage
- HTML email sanitization
- WebSocket-based real-time updates
- Connection status indicator
- Property-based tests for core logic
- Accessibility improvements (ARIA landmarks, focus management, skip links)
- Responsive mobile layout

### Changed
- Complete frontend redesign with design token system
- Rebranded from Webmail to Openvelope
- Migrated to Zustand for state management
- Migrated to Tailwind CSS v4
- Improved motion and animation system

## [0.1.0] - 2026-06-02

### Added
- IMAP/SMTP email support
- Mailbox and folder listing
- Message reading (HTML and plain text)
- Compose, reply, forward email
- Email search across folders
- Attachment upload and download
- Multiple folder navigation
- Go backend with Fiber v3
- PostgreSQL database with GORM
- Single binary deployment with embedded frontend
- YAML configuration
- Docker support
